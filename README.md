# Winter War 2039

I would like all wars to be played on a computer, preferrably that's not
controlling real drones at the same time. That's why I created Winter War 2039:
hopefully it stays as a good game title and there has not to be a war in
2039. The name hints at the [Winter War](https://en.wikipedia.org/wiki/Winter_War)
between Finland and Soviet Union fought in 1939-1940.
